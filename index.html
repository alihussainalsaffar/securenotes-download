Secure Notes

Install Secure Notes

Flutter project by Ali Alsaffar: the note package and the app that uses it

Android

Notes behind your fingerprint, face or screen lock. Add, edit, delete, delete all, drag to reorder, and English or Arabic.

Download for Android (56 MB)
  1. Open the downloaded file.
  2. If asked, allow installing from this source.
  3. Tap Install, then Open, and unlock with your fingerprint or PIN.

The phone needs a screen lock (PIN, pattern or fingerprint) for the app to open.

iPhone

iPhone apps can't be installed from a web page, so this opens the same app in Safari. The browser can't use Face ID, so the web version opens without the lock; the notes are saved in the browser.

Open Secure Notes in the browser
